Paired 1:1 with `make_tts_ethaum.py` (voiceover) and the generated
`ETHAUM_voice_prabhat.mp3` (4:44) / `ETHAUM_voice_neerja.mp3` (4:40) / `ETHAUM_narration.txt`.
Every block below is a section of the narration — start the block's audio, do the block's shots.

**Global settings**
- Screen: 1440×900, browser zoom **110%** so text is readable on a projector; hide bookmarks + devtools.
- Record at **30 fps**, cuts on mouse movement, cursor highlight ON (small amber circle).
- **Burn in captions** (judges watch muted). Auto-captions from the TTS file (Whisper/CapCut) are fine — add a top-left "EthAum" watermark.
- Audio: voiceover at −6 dB under a low, warm bed (no dramatic music stings; this is a clinical story).
- Colour grade slightly warm to match the brand (deep forest + oat + amber).

**Prepare before recording (2 minutes)**
1. Open the app, sign in as **Priya** (`/signin` → "Continue as Priya"), then clear localStorage so the demo starts clean and you can sign in *on camera* in 3 seconds.
2. Open **two tabs** side by side: `/provider/quote-builder` (left) and `/quotes/compare` (right). Keep both visible for the 2:04–2:38 block.
3. Pre-fill the implant brand field on the quote builder: `Xience Xpedition 3.0 · Persona Medacta` — the transparency checks only turn green with a brand named, and you should NOT spend recording time typing.
4. Keep the browser zoom at 110% and don't scroll with the wheel — use `Home`/`End` and arrow keys so the capture stays smooth.
